# MathModelHub

数学建模资源文档中心：帮助你选择工作流、图表和质量检查方法，再前往对应的独立项目执行。

MathModelHub **不再保存比赛现场文件**，也不提供一键运行环境。仓库只维护可长期复用的 Markdown 文档，重点整合三个项目的知识：

- [mma-chart-templates](https://github.com/Jaxon1216/mma-chart-templates)：数学建模数据图模板。
- [MathModel-Skill](https://github.com/yushui2022/MathModel-Skill)：面向正式交付的完整建模工作流。
- [MathModeling-skills](https://github.com/zhnnky329/MathModeling-skills)：强调人在环决策与过程审计的建模工作流。

## Hub 的边界

这里保存的是“如何选择、如何组织、如何验收”，不是上游工具的副本。

- 不保存代码、Notebook、数据集、图片、PDF、Word 或论文模板。
- 不复制完整 Skill 包；安装和运行方法以上游项目为准。
- 不归档比赛题目、队伍草稿或历年论文。
- 不替人做模型选择、结果解释和最终提交决定。

这种边界让 Hub 保持轻量，也避免三个上游项目更新后出现多份互相矛盾的副本。

## 核心原则

1. **人负责判断**：选题、假设、模型路线与结论解释必须由团队确认。
2. **证据先于文字**：论文里的数字、图表和结论必须能追溯到一次真实运行。
3. **先基线后复杂模型**：复杂度必须换来可验证的收益。
4. **图表服务论证**：先确定要表达的关系，再选择图形。
5. **上游独立维护**：Hub 只做稳定知识层，不吞并工具实现。
