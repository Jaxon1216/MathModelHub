# 图表资源目录

[mma-chart-templates](https://github.com/Jaxon1216/mma-chart-templates) 是 MathModelHub 推荐的数学建模数据图模板项目。它把每种图形拆成可注入的绘图模板和人工审核样张；生成脚本、虚拟环境和编译产物不作为分发内容。

## 当前覆盖

- 柱状图
- 分组柱状图
- 堆叠柱状图
- 百分比堆叠柱状图
- 折线图
- 散点回归图
- 箱线图与小提琴图
- 热力图
- 雷达图
- 气泡图
- 双轴图
- 预测区间图
- Tornado 敏感性图
- 网络图
- 多面板组合图

## Hub 与模板仓库的分工

Hub 说明：

- 什么问题适合什么图。
- 哪些图形容易误导。
- 图表进入论文前需要检查什么。

模板仓库提供：

- 可执行绘图模板。
- 样式、布局、配色和标注实现。
- 经人工检查的样张。

需要画图时，先使用[图表选择指南](selection-guide.md)决定图形，再到上游项目取得最新模板。
