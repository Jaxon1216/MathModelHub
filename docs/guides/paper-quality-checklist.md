# 论文质量清单

这份清单用于提交前阻断明显问题。它不能代替赛事规则、专业判断或独立审稿。

## 问题与假设

- [ ] 每个子问题都有明确回答，没有遗漏题目要求的输出。
- [ ] 必要假设与为了简化而做的假设分开陈述。
- [ ] 关键假设有背景依据、数据检查或敏感性分析支持。
- [ ] 符号、单位、下标和缩写全文一致。

## 数据

- [ ] 数据来源、时间范围、样本量和字段含义完整。
- [ ] 原始数据未被覆盖，清洗过程可以复现。
- [ ] 缺失值、异常值和重复记录的处理有量化说明。
- [ ] 外部数据可访问、可引用，没有虚构来源。

## 模型

- [ ] 至少有一个可解释基线。
- [ ] 选择主模型的理由对应题目目标，而不是只因为模型复杂。
- [ ] 方法假设、约束和参数来源明确。
- [ ] 评价指标与任务类型匹配。
- [ ] 训练、验证和测试之间没有信息泄漏。

## 结果与证据

- [ ] 所有正文数字都能追溯到当前运行结果。
- [ ] 代码或数据最后一次变化后，相关结果已经重新生成。
- [ ] 结果包含不确定性、误差或稳定性说明。
- [ ] 结论没有把相关性误写成因果关系。
- [ ] 局限与适用范围真实具体，而不是泛泛而谈。

## 图表

- [ ] 图表类型与分析目的匹配。
- [ ] 坐标、单位、图例、样本范围和方法说明完整。
- [ ] 颜色、符号和精度在全文保持一致。
- [ ] 图表在最终页面尺寸下清晰可读。
- [ ] 正文引用并解释每张图表。

## 写作与结构

- [ ] 摘要包含问题、方法、关键量化结果和直接结论。
- [ ] 章节顺序反映论证逻辑，而不是工作发生的时间顺序。
- [ ] 公式后紧跟变量解释和使用目的。
- [ ] 引用与参考文献一一对应。
- [ ] 没有保留提示词、占位符、内部备注或生成痕迹。

## 提交文件

- [ ] 文件格式、页数、匿名要求和命名符合当届官方规则。
- [ ] 最终文件在另一台设备或干净环境中打开检查过。
- [ ] 字体、公式、图片和链接没有丢失。
- [ ] 提交的是最终版本，且文件摘要或时间戳已记录。
- [ ] 团队成员完成独立交叉检查并明确同意提交。
