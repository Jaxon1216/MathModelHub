# 3 问题一：奖牌预测模型 (Medal Prediction Model)

## 3.1 数据预处理与特征工程 (Data Preprocessing and Feature Engineering)

为确保预测模型的准确性与鲁棒性，对原始数据集进行系统性的清洗、整合及特征提取。

### 3.1.1 数据来源与说明

本研究使用的数据源自官方提供的五个核心文件，涵盖了从1896年雅典奥运会至2024年巴黎奥运会的历史记录。数据的时间跨度达128年，共计30届夏季奥运会，涉及164个国家或地区。表1详细列出了本研究所使用的基础数据表及其功能。

**Table 1: Description of Raw Data Files**

| 文件名 | 数据内容描述 | 在建模中的主要用途 |
| :--- | :--- | :--- |
| `summerOly_medal_counts.csv` | 历届各国奖牌统计 | 核心预测目标与历史基准 |
| `summerOly_hosts.csv` | 历届奥运会主办城市 | 提取“东道主效应”特征 |
| `summerOly_programs.csv` | 历届比赛项目清单 | 计算奖牌占比及归一化处理 |
| `summerOly_athletes.csv` | 运动员竞赛明细 | 分析项目优势与运动员规模 |
| `data_dictionary.csv` | 字段语义定义 | 确保变量解析的准确性 |

### 3.1.2 数据清洗与一致性处理

针对原始数据中存在的异质性与潜在噪声，我们实施了以下预处理步骤：

1.  **缺失值识别与处理**：经检测，核心奖牌数据表中不存在缺失记录。对于特定年份未出现在奖牌表中的国家，统一将其奖牌数填充为0，以确保时间序列的完整性。
2.  **历史实体的保留策略**：针对苏联、东德等已解体或改名的历史实体，本研究决定**保留原始记录**而非将其并入现代继承国。原因在于历史表现是重要的预测信号，简单合并会扭曲统计特征。
3.  **文本字符清洗**：针对字段中存在的特殊空格字符（`\xa0`），本研究进行了统一替换与去噪，确保了跨表关联时的匹配准确度。

### 3.1.3 数据整合与指标归一化

本研究以奖牌统计表为主表，通过左连接（Left Join）方式整合了东道主信息与项目总数。

* **东道主识别**：构建二值变量 $is\_host$。若该国是当届奥运会的东道主，则 $is\_host = 1$，否则为 $0$。
* **奖牌占比归一化**：考虑到历届奥运会项目数量从1896年的43项增至2024年的329项，本研究引入“奖牌占比”指标以实现跨年份的公平比较：
    $$\text{medal\_ratio}_{i,t} = \frac{\text{TotalMedals}_{i,t}}{\text{TotalEvents}_t}$$

### 3.1.4 特征工程

基于体育竞技的惯性效应与周期性规律，构建多维特征矩阵：

**滞后特征（Lag Features）**：利用历史成绩预测未来表现，提取上一届（Lag1）及上两届（Lag2）的奖牌数据：

$$
\text{lag}_1(i,t) = \text{TotalMedals}_{i,t-4}
$$

**滚动平均特征（Rolling Features）**：为衡量稳定实力，计算近三届（约12年周期）的平均奖牌数：

$$
\bar{M}_3(i,t) = \frac{1}{3}\sum_{k=1}^{3} \text{TotalMedals}_{i,t-4k}
$$

**衍生统计特征**：构建参赛届数（$\text{participation\_count}$）、金牌占比（$\text{gold\_ratio}$）及奖牌变化量（$\text{total\_change}$）等辅助变量。

### 3.1.5 特征有效性验证

为验证所选特征的解释力，计算各特征与总奖牌数的Pearson相关系数，结果如Table 2所示。

**Table 2: Correlation Analysis between Features and Total Medals**

| 特征变量 | 含义说明 | 相关系数 | 重要性 |
| :--- | :--- | :---: | :---: |
| `total_rolling3_mean` | 近3届平均奖牌数 | 0.835 | 极高 |
| `total_lag1` | 上一届奖牌总数 | 0.800 | 极高 |
| `gold_lag1` | 上一届金牌总数 | 0.791 | 极高 |
| `is_host` | 是否为东道主 | 0.368 | 中等 |
| `participation_count` | 历史参赛届数 | 0.232 | 较低 |

分析结果表明，历史表现特征（滚动平均与滞后项）具有极强的预测价值，相关系数均超过0.79。最终生成包含1,435条记录、16个特征字段的结构化分析主表。

## 3.2 模型选择与特征分析

### 3.2.1 建模方法选择与适用性论证

奥运奖牌预测本质上属于数值回归问题，其目标变量（金牌数和总奖牌数）为连续数值型数据。基于这一特征，采用回归分析方法而非分类方法进行建模。回归模型能够建立自变量（如历史成绩、东道主效应等）与因变量（奖牌数）之间的数学关系，从而实现对未知值的预测。

构建多元回归预测框架的依据如下：

1. **目标变量连续性**：奖牌数为非负整数，属于连续数值预测范畴
2. **多因素影响**：奖牌分布受经济、人口、历史表现、东道主优势等多重因素共同作用
3. **数据可获取性**：所需特征变量在预测时点均已知，避免数据泄露问题

### 3.2.3 东道主效应验证与统计检验

东道主效应（Home Advantage）是奥运奖牌预测中不可忽视的重要因素。通过统计方法验证并量化这一效应：

**描述性统计对比**：东道主国家平均获得66.9枚奖牌，显著高于非东道主国家的11.3枚，增幅达491.9%，如Fig. 4(a)所示。

**独立样本t检验**：为验证差异的统计显著性，进行双样本t检验：

$$
t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}} = 15.0
$$

计算得到p值<0.001，远小于显著性水平α=0.05，拒绝原假设，表明东道主效应具有统计显著性。

**效应量分析**：采用Cohen's d衡量效应大小：

$$
d = \frac{\bar{X}_1 - \bar{X}_2}{s_{\text{pooled}}} = 2.77
$$

根据Cohen标准（d>0.8为大效应），东道主效应属于大效应范畴。上述分析为后续模型中将东道主身份作为重要特征提供了坚实的统计学依据。

## 3.3 回归模型构建与评估

### 3.3.1 线性回归与正则化方法

首先构建多元线性回归作为基线模型：
$$
\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_7 x_7
$$

其中$\hat{y}$为预测奖牌数，$\beta_i$为特征系数，$x_i$为特征值。模型纳入的特征变量包括：`total_lag1`（上届总奖牌数）、`total_lag2`（上两届总奖牌数）、`gold_lag1`（上届金牌数）、`total_rolling3_mean`（近三届平均奖牌数）、`is_host`（东道主标识）、`total_events`（当届项目总数）及`participation_count`（参赛届数）。

针对特征间可能存在的多重共线性问题，引入正则化方法：

- **Ridge回归**（L2正则化）：通过惩罚系数平方和防止过拟合
- **Lasso回归**（L1正则化）：通过惩罚系数绝对值实现特征选择

Lasso回归的损失函数定义为：

$$
L = \sum_{i=1}^{m}(y_i - \hat{y}_i)^2 + \alpha \sum_{j=1}^{n}|\beta_j|
$$

其中$\alpha$为正则化强度参数。

### 3.3.2 集成学习模型

为进一步提升模型性能，引入两种集成学习算法：

**随机森林（Random Forest）**：通过构建多棵决策树并取平均预测，降低过拟合风险。模型能够捕捉特征间的非线性关系，并提供特征重要性排序，如Fig. 5所示。最重要的三个特征依次为：`gold_lag1`（重要性0.345）、`total_lag1`（重要性0.332）、`total_rolling3_mean`（重要性0.151）。

**梯度提升（Gradient Boosting）**：采用串行迭代方式，后一棵树专门纠正前一棵树的残差。这种"纠错学习"机制通常能获得更高的预测精度，但也更易过拟合。

### 3.3.3 模型评估与性能比较

采用多种指标综合评估模型性能：

- **RMSE（均方根误差）**：$\text{RMSE} = \sqrt{\frac{1}{m}\sum_{i=1}^{m}(y_i - \hat{y}_i)^2}$
- **MAE（平均绝对误差）**：$\text{MAE} = \frac{1}{m}\sum_{i=1}^{m}|y_i - \hat{y}_i|$
- **R²（决定系数）**：$R^2 = 1 - \frac{\sum_{i=1}^{m}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{m}(y_i - \bar{y})^2}$

## 3.4 2028年奖牌预测与结果分析

### 3.4.1 奖牌榜预测与置信区间

基于最佳模型（Lasso回归），对2028年洛杉矶奥运会奖牌榜进行预测。为确保预测可靠性，采用Bootstrap方法计算95%置信区间：

1. **Bootstrap原理**：从训练数据中有放回地重复抽样，构建多个伪训练集
2. **模型重训练**：在每个伪训练集上重新训练Lasso模型
3. **预测分布**：使用所有模型对同一国家进行预测，形成预测值分布
4. **置信区间**：取分布的第2.5%和第97.5%分位数作为95%置信区间

$$
\text{95\% CI} = [\text{Percentile}_{2.5}, \text{Percentile}_{97.5}]
$$

### 3.4.2 首次获奖国家预测与概率估计

首次获奖国家数量符合稀有事件发生特征，采用泊松分布（Poisson Distribution）进行建模：

$$
P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}
$$

其中$X$为首次获奖国家数，$\lambda$为平均发生率。基于2000年以来历史数据（平均每届5.7个国家首次获奖），设置$\lambda=5.8$，得到2028年预测分布如Table 5所示。

**Table 5: Probability Distribution of First-time Medal Winners**

| 首次获奖国家数 | 概率 | 累积概率 |
|:---------------:|:------:|:----------:|
| ≤3 | 17.00% | 17.00% |
| 4 | 14.28% | 31.27% |
| **5** | **16.56%** | **47.83%** |
| **6** | **16.01%** | **63.84%** |
| 7 | 13.26% | 77.10% |
| ≥8 | 22.90% | 100.00% |

**预测结论**：

1. **期望值**：$E(X) = \lambda = 5.8$个国家（约6个）
2. **90%预测区间**：[2, 10]个国家
3. **最可能结果**：5-6个国家首次获奖（联合概率32.57%）

这一预测与历史趋势基本一致，如Fig. 9所示，反映了奥运奖牌分布缓慢分散化的长期趋势。

### 3.5.2 项目数量对奖牌分布的影响

奥运会项目数量从1896年的43个增加至2024年的329个，这一变化对奖牌分布产生显著影响：

**奖牌分散化效应**：项目增加为更多国家提供了获奖机会。早期奥运会奖牌集中于少数传统强国；现代奥运会获奖国家数量显著增加，中小型体育国家能够通过优势项目实现突破。

**东道主项目策略**：主办国可在一定程度上影响项目设置，具体机制包括：

- **新增本国优势项目**：提高本土运动员获奖概率
- **调整比赛规则**：适应本国运动员的技术特点
- **场地设施优势**：东道国运动员可提前适应比赛环境

**项目类型与奖牌产出关系**：不同项目的奖牌产出效率存在显著差异。游泳、田径等高产项目奖牌数多、竞争激烈；而部分国家在特定项目上形成垄断优势，如中国在跳水、乒乓球项目上的统治地位。

项目数量与获奖国家数的正相关关系表明，奥运会项目扩张促进了全球体育发展的均衡性，为更多国家提供了展示体育实力的平台。
